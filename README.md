# Firewall-UI

Веб-панель для управления файрволлом Linux. Показывает занятые порты и процессы, позволяет настраивать правила доступа.

[Релизы](https://github.com/SawaMEN/Firewall-UI/releases) · [Сообщить об ошибке](https://github.com/SawaMEN/Firewall-UI/issues)

## Возможности

- Управление UFW, firewalld, nftables и iptables.
- Мониторинг TCP/UDP-портов и процессов, включая опубликованные порты Docker/Podman.
- Группировка портов по процессам и диапазонам без объединения пропусков.
- Открытие и закрытие портов, правила для диапазонов, IP и подсетей.
- Резервные копии и автоматический откат при потере доступа после изменения правил.
- Доступ по домену или IP с HTTPS.
- Установка готового бинарника или Docker-образа с проверкой SHA-256, без сборки на сервере.

## Установка и обновление

Нужен Linux с systemd, архитектура **amd64** или **arm64**.

```bash
curl -fsSL https://raw.githubusercontent.com/SawaMEN/Firewall-UI/main/install.sh | sudo bash
```

В русском меню выберите **1) Установить / обновить**, затем вариант:

| Выбор | Установка |
| --- | --- |
| **1** | Готовый бинарник и служба systemd |
| **2** | Готовый Docker-образ; установщик проверит необходимые компоненты |
| **0** | Назад |

Эта же команда обновляет существующую установку с сохранением настроек и данных. Для Docker доступны обновление из веб-панели и автоматическая проверка stable-релизов каждый час. Расписание включается при установке; изменить его можно в меню **Настройки → Автообновление Docker**. При обычной установке скрипт проверяет файрволл и устанавливает UFW, если поддерживаемый файрволл не найден. Существующие правила сохраняются; UFW автоматически не включается.

Мастер предложит логин, пароль, порт и способ доступа:

| Режим | Подключение |
| --- | --- |
| Локальный | Только с сервера или через SSH-туннель; по умолчанию `http://127.0.0.1:8088` |
| Домен | `https://panel.example.com:порт` |
| IP | `https://IP:порт` |

Для HTTPS доступны готовые PEM-файлы, Let’s Encrypt и самоподписанный сертификат. Самоподписанный сертификат вызовет предупреждение браузера. Let’s Encrypt требует свободного TCP-порта 80, доступного из интернета; домен должен указывать на сервер. Для сертификата IP нужен Certbot 5.3 или новее. Порт панели также разрешите в файрволле хостинга.

Для локального режима создайте SSH-туннель на своём компьютере:

```bash
ssh -L 8088:127.0.0.1:8088 user@server
```

Откройте `http://127.0.0.1:8088` в браузере.

Docker-версия использует сеть хоста и расширенные права для управления его файрволлом. Одновременно используйте один вариант панели.

## Управление

```bash
sudo fw-ui
```

В меню доступны настройки подключения, сброс пароля, управление службой и полное удаление. Журнал и диагностика — в **5) Управление службой**. Подтверждение — **`y/n`**, возврат и выход — **`0`**.

| Команда | Действие |
| --- | --- |
| `sudo fw-ui status` | Состояние службы |
| `sudo fw-ui start` / `stop` / `restart` | Запуск, остановка, перезапуск |
| `sudo fw-ui logs` | Журнал |
| `sudo fw-ui credentials` | Изменить логин и пароль |
| `sudo fw-ui reset-password` | Сбросить пароль |
| `sudo fw-ui uninstall --purge` | Полностью удалить оба варианта |

Полное удаление убирает файлы панели, её данные, контейнеры, тома, собственные правила и запрет пинга. Системный файрволл, Docker Engine, чужие правила и ресурсы сохраняются.

Если панель не открывается, проверьте состояние и журнал, выбранный режим доступа и разрешение порта у хостинга.
