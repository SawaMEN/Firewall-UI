# Firewall-UI

Веб-панель для управления файрволлом Linux. Показывает занятые порты и процессы, позволяет настраивать правила доступа.

[Релизы](https://github.com/SawaMEN/Firewall-UI/releases) · [Сообщить об ошибке](https://github.com/SawaMEN/Firewall-UI/issues)

## Возможности

- Управление UFW, firewalld, nftables и iptables.
- Мониторинг TCP/UDP-портов и процессов, включая опубликованные порты Docker/Podman.
- Группировка портов по процессам и диапазонам без объединения пропусков.
- Открытие и закрытие портов, правила для диапазонов, IP и подсетей.
- Резервные копии и автоматический откат при потере доступа после изменения правил.
- Доступ по домену или IP с HTTPS.
- Установка готового бинарника или Docker-образа с проверкой SHA-256, без сборки на сервере.

## Установка и обновление

Linux с systemd, **amd64** или **arm64**.

```bash
curl -fsSL https://raw.githubusercontent.com/SawaMEN/Firewall-UI/main/install.sh | sudo bash
```

Выберите **1) Установить / обновить**, затем:

| Выбор | Вариант |
| --- | --- |
| **1** | Бинарник |
| **2** | Docker |
| **0** | Назад |

## Управление

```bash
sudo fw-ui
```

В меню доступны настройки подключения, сброс пароля, управление службой и полное удаление. Журнал и диагностика — в **5) Управление службой**. Подтверждение — **`y/n`**, возврат и выход — **`0`**.

| Команда | Действие |
| --- | --- |
| `sudo fw-ui status` | Состояние службы |
| `sudo fw-ui start` / `stop` / `restart` | Запуск, остановка, перезапуск |
| `sudo fw-ui logs` | Журнал |
| `sudo fw-ui credentials` | Изменить логин и пароль |
| `sudo fw-ui reset-password` | Сбросить пароль |
| `sudo fw-ui uninstall --purge` | Полностью удалить оба варианта |

Полное удаление убирает файлы панели, её данные, контейнеры, тома, собственные правила и запрет пинга. Системный файрволл, Docker Engine, чужие правила и ресурсы сохраняются.

Если панель не открывается, проверьте состояние и журнал, выбранный режим доступа и разрешение порта у хостинга.
