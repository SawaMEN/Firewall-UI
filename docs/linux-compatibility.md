# Совместимость с Linux

Проверка охватывает текущий код на amd64. Стенд запускает настоящие systemd,
пакеты дистрибутива, бинарник панели и правила ядра в отдельном сетевом пространстве.
Это проверка пользовательского окружения на ядре Ubuntu CI, а не загрузка
отдельного ядра каждого дистрибутива.

Сценарий: установка, запуск службы, вход, определение процесса занятого порта,
открытие/закрытие портов, удаление отдельного правила, запрет пинга,
повторная установка с сохранением данных, сброс пароля и полное удаление.
Проверяется очистка своих правил и сохранение чужого правила.

| Окружение | Файрволл | Результат |
| --- | --- | --- |
| Arch Linux (rolling, amd64) | UFW | Сценарий пройден |
| Debian 13 (amd64) | UFW | Сценарий пройден |
| Fedora 44 (amd64) | firewalld | Сценарий пройден |
| Fedora 44 (amd64), дополнительная попытка | UFW 0.35 | Включение в стенде завершилось ошибкой |
| openSUSE Leap 16.0 (amd64) | firewalld | Сценарий пройден |
| Ubuntu 24.04, Docker Compose (amd64/arm64) | UFW хоста | Отдельный Docker CI пройден |

## Границы поддержки

- Установщик и менеджер требуют запущенный systemd. Alpine с OpenRC,
  Devuan и другие системы с другим init не поддерживаются этим установщиком.
- Arch использует `pacman`; UFW, Docker и Docker Compose доступны из Extra.
  Проверка rolling-образа предварительно обновляет его целиком. Установщик
  не выполняет принудительное обновление всей системы пользователя.
- При наличии UFW, firewalld, nftables или iptables используется имеющийся
  файрволл. Если их нет, установщик пытается установить UFW из настроенных репозиториев.
- В AlmaLinux/Rocky/RHEL доступность UFW зависит от EPEL. Docker-установщик
  для систем с `dnf` использует `moby-engine`, наличие которого в Fedora
  не означает наличие в базовых репозиториях RHEL. Полный сценарий этих
  дистрибутивов не подтверждён; наличие одного пакетного менеджера недостаточно.
- Fedora и openSUSE проверяются с установленным firewalld.
  Дополнительная попытка Fedora с UFW 0.35 не прошла включение: сначала
  контейнеру не хватало доступа к модулям ядра; после их подключения UFW
  вернул `ERROR: problem running`. Причина второго отказа не установлена;
  поддержку этого сочетания нельзя считать подтверждённой.
- Чистая установка Fedora/openSUSE без поддерживаемого файрволла отдельно
  не подтверждена.
- Проверка дистрибутивов выполнена для обычной установки на amd64.
  Docker на этих хостах, SELinux enforcing, перезагрузка отдельной VM,
  получение публичных TLS-сертификатов и все версии дистрибутивов не проверены
  данным сценарием. Архитектура arm64 проверяется отдельной сборкой и Docker CI.
