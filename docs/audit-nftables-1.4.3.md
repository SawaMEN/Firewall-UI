# Дополнительные исправления nftables — 1.4.3

База: 1.4.2 (`395f27d36efb73415e6b5586ff4ca6209ef5047c`).

| Ошибка | Исправление |
|---|---|
| Успешный exit установки дополнительной таблицы считался достаточным; ошибки чтения результата игнорировались. | До заполнения кеша проверяются JSON, активный FORWARD hook и все сохранённые закрытия в INPUT/FORWARD. |
| Проверка native-политики не подтверждала наличие, порядок и verdict расширенных правил; установка общей защиты контейнеров не подтверждала полный набор отмеченных правил. | После применения сверяются упорядоченные комментарии и terminal verdict: native advanced и container allow/block/advanced/safety. Точные условия индивидуальных закрытий проверяются отдельно. |
| FORWARD chain без прежних DROP/ALLOW продолжала отображаться активной. | Статус требует неизменённого снимка последнего подтверждённого применения. После запуска до первой сверки статус остаётся неподтверждённым. |
| Диагностика моделировала сохранённые правила при изменившемся ядре и пропускала защитные FORWARD-исключения панели/SSH перед advanced deny. | При неподтверждённом/изменённом снимке — unknown; системные защитные DNAT-исключения учитываются до advanced только при наличии точного ALLOW в ядре. Новый порт из запроса не считается установленным исключением. |
| Код успешного удаления таблицы принимался за отключение; сохранённый native OFF только подавлял синхронизацию, оставляя фильтрацию после прерванного отключения. | Повторно проверяется список таблиц; native-сверка при OFF удаляет оставшийся owned backend и дополнительную таблицу. |
| Текущий safety port передавался в INPUT, но дополнительная политика использовала только ранее запомненный порт. | Запрошенный safety port передаётся и при синхронизации дополнительной таблицы. |
| Статистика принимала JSON без массива nftables за пустые счётчики. | Используется общий строгий декодер; ошибочный снимок возвращает ошибку. |

## Проверки и границы

- Go unit/regression с `-race`, `go vet`, форматирование.
- Frontend: 23 теста, TypeScript и production build; браузерные регрессии CI.
- Изолированные kernel-тесты: TCP/UDP IPv4/IPv6 INPUT и DNAT/FORWARD,
  закрытие/повтор/открытие, dormant, восстановление, CIDR/интерфейсы/диапазоны/приоритеты,
  42 синтаксические комбинации advanced.
- Добавлены kernel-проверки: сохранённый OFF с оставшейся native-таблицей,
  диагностика защищённой DNAT-панели при broad deny, статус и unknown после flush FORWARD.
- Unit-проверки отклоняют пустую/нечитаемую/некорректную таблицу после успешной
  команды, пропавший закрытый порт, перестановку правил, изменённый verdict и no-op delete.

Это проверка реализации и воспроизводимых сценариев, а не доказательство
отсутствия всех возможных ошибок. Исходный рабочий сервер пользователя не
изменялся. Проверка marked rules подтверждает наличие, порядок и verdict;
она не является универсальным доказательством эквивалентности произвольных
nftables-выражений. Полный отпечаток обнаруживает последующее изменение
снимка, но внешний процесс всё равно может изменить правила после проверки.
Сторонние INPUT hooks не удаляются; ограничения смешанных установок и версий
ядра из отчёта 1.4.2 сохраняются.
