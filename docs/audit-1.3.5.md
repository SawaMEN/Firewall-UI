# Проверка 1.3.5

Проверены загрузка интерфейса, маршруты API, обновление, ручной перезапуск,
отложенный откат правил, обзор портов и чтение журналов.
200 независимых ошибок не подтверждено. Ниже перечислены реальные исправления;
повторы в двух журналах или двух языках не считаются отдельными ошибками.

| Проблема | Исправление |
| --- | --- |
| Отступы увеличивали полноэкранный загрузчик сверх ширины экрана | `border-box`; проверка центра и переполнения на двух размерах экрана |
| Docker проверял stable при выбранном dev | Проверяется настроенный канал |
| Docker-обновление читало конфигурацию без блокировки | Чтение под общей блокировкой конфигурации |
| Ручной перезапуск/обновление прерывали ожидающий откат правил | Запрет до подтверждения транзакции |
| Новые изменения принимались после назначения перезапуска | Защита периода до перезапуска и состояния обновления |
| Ошибка предыдущей Docker-попытки могла появиться при повторе в ту же секунду | Сравнение точного времени файла с временем нового запроса |
| Кнопка проверки обновлений возвращала устаревший кэш | Явная проверка запрашивает свежие метаданные |
| Параллельные проверки повторно скачивали одни метаданные | Один общий запрос и повторная проверка кэша |
| Проверки браузера могли перекрываться | Отдельный контроль запроса с учётом отмены |
| Обновление преждевременно сообщало новую текущую версию | Текущая версия соответствует работающему процессу |
| Поток портов продолжал работу после ошибки записи | Немедленное закрытие обработчика |
| Обзор не учитывал прослушивание конкретного сетевого IP | Учитываются IPv4/IPv6, loopback исключён |
| JSON `null` в API принимался как пустые настройки | Требуется объект; сохранена проверка неизвестных полей и лишних данных |
| JSON `null` принимался как конфигурация по умолчанию | Ошибка без перезаписи исходного файла |
| Длинная строка журнала скрывала все последующие записи | Пропуск повреждённой строки с продолжением чтения |
| Запись принимала данные, которые чтение не могло обработать | Одинаковые ограничения размеров записи и чтения |
| JSON `null` создавал пустую запись журнала | Пропуск пустых JSON-записей |

Удалены старый префикс `/panel/api/server/firewall`, его Vite-прокси,
неиспользуемая обёртка восстановления и неиспользуемые тексты подтверждения.
Объединены два дублирующихся JSON-декодера. Два повторяющихся обработчика журналов заменены общим читателем с кольцевым буфером.
Код миграции установленных версий и очистки старых правил сохранён: он нужен
для обновления и полного удаления существующих установок.

Проверки: shell-сценарии установки/удаления/переключения, тесты интерфейса,
TypeScript и production-сборка локально; Go race/vet, форматирование,
Playwright и Docker-сборка выполняются в GitHub Actions.
